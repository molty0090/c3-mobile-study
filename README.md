# C3安全员刷题手册

在线刷题：<https://molty0090.github.io/c3-mobile-study/>

手机浏览器直接访问，无需登录 ChatGPT。2000题，200题一组，支持背题、自测、错题练习、模拟考、大字阅读和学习进度备份。

## 小测与模拟考试

刷题页面点“错题集”旁的 **小测**，会打开设置并直接定位到题量选择。可选本组20题（20分钟）、50题（40分钟）、100题（60分钟），再点“开始本组小测”。选“全题库”时从全库抽题。

“全库模拟考”抽40道单选、20道多选、40道判断，限时60分钟。可暂离并继续未交卷考试，交卷后查看成绩及错题解析。以上是练习评分，非官方考试系统。

也可从“更多 → 分组练习、小测与模拟考试”进入。

## 添加到手机桌面

网页内完整说明位于“更多 → 添加到手机桌面”，默认收起，不占刷题空间。

- **iPhone**：用 Safari 打开网页 → 分享（部分布局先点页面菜单）→ 添加到主屏幕 → 添加。找不到时在分享菜单的“编辑操作”中添加该项。
- **安卓 Chrome**：打开网页 → ⋮ 菜单 → 添加到主屏幕；部分版本为“安装并创建快捷方式 → 创建快捷方式”→ 添加并确认。
- 在微信等内置浏览器中找不到入口时，先切换到手机浏览器。

官方步骤：[Apple](https://support.apple.com/zh-cn/guide/iphone/iph42ab2f3a7/ios)、[Chrome](https://support.google.com/chrome/answer/15085120?co=GENIE.Platform%3DAndroid&hl=zh-CN)。菜单名称可能随版本不同。

## 保存学习进度

学习记录自动保存在当前设备的浏览器或网页 App 中，不会跨设备自动同步。建议固定从同一桌面图标进入；不同入口可能拥有独立记录。

在“更多 → 导出学习备份”下载备份文件，在“恢复备份”中导入。切换入口、清理网站数据、删除网页 App 或换手机前请先备份；避免无痕模式。

桌面图标是快捷入口，不表示已安装离线题库。当前版本不提供完整离线缓存，加载网页需要网络。
